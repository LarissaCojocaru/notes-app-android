# 📝 Notes App - Android

O aplicație mobilă nativă pentru Android, concepută pentru a crea, gestiona și organiza notițe personale într-un mod simplu și eficient. 

## ✨ Funcționalități Principale

* **Creare și Editare:** Adaugă notițe noi și modifică-le pe cele existente cu ușurință.
* **Ștergere:** Elimină rapid notițele de care nu mai ai nevoie.
* **Interfață Intuitivă (UI):** Design curat și prietenos, optimizat pentru ecranele dispozitivelor mobile.
* **Stocare Locală:** Notițele sunt salvate direct pe dispozitivul tău pentru acces instantaneu (offline).

## 🛠️ Tehnologii Utilizate

* **Limbaj:** Java / Kotlin 
* **Mediu de dezvoltare:** Android Studio
* **Design Interfață:** XML
* **Bază de date/Stocare:** SQLite
